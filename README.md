# SocialBoost

פלטפורמה אוטומטית לקידום ברשתות חברתיות באמצעות חשבונות Temp Mail ואוטומציית דפדפן.

## מה זה עושה
מזינים קישור + פעולה (לייק / צפייה / מנוי) + כמות, והמערכת יוצרת חשבונות אוטומטית דרך דואר זמני
ומבצעת את הפעולות דרך Playwright.

## הרצה מקומית

פתח את האתר בכתובת GitHub Pages והדבק את כתובת הבק`נד בשדה העליון.
